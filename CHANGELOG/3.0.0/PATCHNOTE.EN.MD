# 3.0.0

## What's New

- Added the new Menu and Preferences UI.
- Added Stable, Staging, and Nightly release channels.
- Added the Bundle, Provider, and Plugin architecture.
- Moved built-in site integrations into the built-in Bundle.
- Added the unified frameless Picture in Picture mode.
- Added local video and HLS playback powered by electron-mpv-video.

## Detail

- Added isolated, user-defined, and Plugin-provided browser profiles.
- Added `.kawai` Bundle installation, explicit permission approval, and runtime validation.
- Added Provider-scoped injections, navigation policy, PiP policy, and request interception.
- Added channel-locked automatic updates and versioned release notes.
- Added configurable YouTube Shorts and CHZZK Clips auto-advance with PiP-global previous, next, and toggle shortcuts.
- Added Provider-declared Bundle settings and YouTube Shorts publisher quick-ban with an editable ban list.
- Split new remote page injections into feature-oriented TypeScript modules.
