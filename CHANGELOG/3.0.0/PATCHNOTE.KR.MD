# 3.0.0

## 새로운 기능

- 새로운 메뉴 및 Preference UI를 추가했습니다.
- Stable, Staging, Nightly 릴리스 채널을 추가했습니다.
- Bundle, Provider, Plugin 구조를 추가했습니다.
- 기본 사이트 연동을 Built-in Bundle로 분리했습니다.
- Frameless 기반 통합 PiP 모드를 추가했습니다.
- electron-mpv-video 기반 로컬 영상 및 HLS 재생을 추가했습니다.

## 세부 변경 사항

- 사이트 격리 프로필과 사용자 및 Plugin 제공 브라우저 프로필을 추가했습니다.
- `.kawai` Bundle 설치, 명시적 권한 승인, 런타임 검증을 추가했습니다.
- Provider별 Injection, 탐색 정책, PiP 정책, 요청 가로채기를 추가했습니다.
- 채널별 자동 업데이트와 버전별 업데이트 내역을 추가했습니다.
- YouTube 쇼츠와 치지직 클립 자동 넘김 옵션 및 PiP 전역 이전·다음·전환 단축키를 추가했습니다.
- Provider 선언형 Bundle 설정과 편집 가능한 YouTube 쇼츠 게시자 빠른 차단 목록을 추가했습니다.
- 새 원격 페이지 Injection을 기능별 TypeScript 모듈로 분리했습니다.
