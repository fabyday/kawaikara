카와이카라는 Electron 기반 OTT 뷰어입니다. 브라우저 주소창이나 불필요한 UI 없이, 디스코드 방송에 맞는 작고 편한 창으로 OTT 서비스를 보는 데 초점을 둡니다.

## 주요 기능

- PiP(Picture in Picture).
- 사용자가 지정한 창 크기에서 전체화면 보기.
- 친구와 디스코드에서 OTT 보기.
- 유튜브 동영상 다운로드 지원.
- macOS 지원(실험적).
- 외부 브라우저 로그인 지원.

## 기본 사용법

1. `Tab` 키를 눌러 메뉴를 엽니다.
2. 원하는 서비스를 선택합니다.
3. 서비스를 이용합니다.

단축키:

- 메뉴 열기: `Tab`
- 전체화면 켜기/끄기: `Alt+Enter`
- 다운로드 디렉토리 열기: `메뉴 > 옵션 > 다운로드 디렉토리`

## 디스코드 활동 상태

직접 빌드하는 경우 디스코드 Rich Presence를 사용하려면 프로젝트 최상위 폴더에 `.env` 파일을 만드세요.

```shell
DISCORD_APP_ID=${앱_아이디}
DISCORD_PUB_KEY=${앱_퍼블릭_키}
```

## DRM 참고

Electron은 기본적으로 CDM을 지원하지 않습니다. 카와이카라는 DRM이 필요한 서비스를 지원하기 위해 CastLabs의 Electron 포크를 사용합니다.

## 직접 빌드하기

먼저 Node.js 환경을 준비하세요. 루트 README는 `nvm`과 `yarn` 사용을 권장합니다.

빌드 전에 CastLabs 계정을 만들고 인증합니다.

```shell
conda create -n test_env python=3.10
conda activate test_env
pip install castlabs_evs

python -m castlabs_evs.account signup
python -m castlabs_evs.account reauth -A ${your_account} -P ${your_password}
```

### Windows 빌드

프로젝트 디렉토리에서 PowerShell로 실행하세요.

```shell
yarn install
yarn make-cert:win
yarn build
```

### macOS 빌드

프로젝트 디렉토리에서 PowerShell로 실행하세요.

```shell
yarn install
yarn make-cert:mac
yarn build
```
