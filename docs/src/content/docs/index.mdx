Kawaikara is an Electron-based OTT viewer focused on compact streaming windows, PiP, fullscreen viewing, and Discord watch workflows.

## Current Direction

The app is being moved into a clearer package layout:

- `src/main` owns Electron windows, BrowserViews, update flow, keyboard handling, menus, site descriptors, and app state.
- `src/preload` exposes the safe renderer API through `window.KAWAI_API`.
- `src/renderer` owns the React views bundled into `dist/pages`.

The production build compiles main, preload, and renderer separately with webpack, then Electron loads `dist/main/main.js`.

## App Surfaces

- Main window: service launcher and active streaming view.
- Menu overlay: service/category selector shown over the main window.
- Update overlay: update progress and actions shown over the main window at the same bounds as the menu overlay.
- Preferences window: configuration UI for general settings, window sizing, PiP, locale, and shortcuts.
- Background task window: long-running task status.

## Verification Targets

The baseline completion checks are:

- `pnpm typecheck`
- `pnpm build`
- `pnpm package:kawaikara:dir`
- short Electron smoke runs for dev and packaged app folders
